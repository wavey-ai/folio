      Universal document schema

      One schema for every document

      Every scalar value becomes one row in nodes. Rows with the same name and id form one inferred record.

      XML attributes use paths that start with @. Element text uses $text. Each row keeps the element hierarchy through parent_id.

      Use WITH RECURSIVE to follow parent_id through every level. Traverse _tree rows, then join scalar values by id.

      Every value keeps six coordinates

      idparent_idnamepathdata_typevalue
      One inferred recordIts containing recordThe inferred tableThe scalar fieldString, number, or booleanThe original scalar text

      Query the universal schema

      Build complete records
      WITH RECURSIVE records AS (
  SELECT id, parent_id,
  max(value) FILTER (WHERE path = 'name') AS name
  FROM nodes
  WHERE name = 'document__items'
  GROUP BY id, parent_id
)
SELECT * FROM records;
      Follow every level with WITH RECURSIVE
      WITH RECURSIVE tree AS (
  SELECT id, parent_id, value AS table_name, 0 AS depth
  FROM nodes
  WHERE name = '_tree' AND parent_id IS NULL
  UNION ALL
  SELECT child.id, child.parent_id, child.value, tree.depth + 1
  FROM tree
  JOIN nodes AS child ON child.parent_id = tree.id
  WHERE child.name = '_tree'
)
SELECT table_name, depth, id, parent_id
FROM tree
ORDER BY depth, table_name;
