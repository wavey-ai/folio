One schema for every document

How Folio stores your document

Every scalar value becomes one row in nodes. Rows with the same name and id form one inferred record.

id
Identifies one inferred record.
parent_id
Connects a child record to its container.
name
Names the inferred table.
path
Names the scalar field.
data_type
Records string, number, or boolean.
value
Contains the scalar value as text.
Build a record 
SELECT id, parent_id,
  max(value) FILTER (WHERE path = 'name') AS name
FROM nodes
WHERE name = 'document__items'
GROUP BY id, parent_id;
Follow the document structure 
SELECT child.value, parent.value
FROM nodes AS child
JOIN nodes AS parent
  ON child.parent_id = parent.id;
