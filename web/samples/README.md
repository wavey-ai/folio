# Reactome BioPAX sample

`reactome-pathways.xml` contains the Reactome pathways for *Plasmodium falciparum*.

The file comes from Reactome release 97. The retrieval date is August 23, 2026.

Reactome provides the source file in the `biopax.zip` download package:
